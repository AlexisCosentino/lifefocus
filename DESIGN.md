# LIFE FOCUS — DIRECTION ARTISTIQUE

## Positionnement

Life Focus est un site de photographie de mariage et de famille basé dans la Drôme.

Le site doit évoquer un magazine photographique haut de gamme : éditorial, minimaliste, humain et intemporel.

Le design ne doit jamais prendre le dessus sur les photographies.

Les photographies constituent la principale source de couleur du site.

## Principes visuels

Le site doit être :

* très épuré ;
* éditorial ;
* élégant ;
* chaleureux ;
* photographique ;
* haut de gamme sans être prétentieux ;
* moderne sans suivre les effets de mode web.

Le site ne doit PAS ressembler :

* à un site SaaS ;
* à un template généré par IA ;
* à un site de mariage bohème beige générique ;
* à une galerie d’art froide ou inaccessible.

## Palette

Fond principal : ivoire très clair / blanc cassé.

Exemple de référence :

`#F5F3EE`

Texte principal : charbon.

Exemple :

`#161616`

Les couleurs supplémentaires doivent être extrêmement rares.

Les photographies doivent fournir presque toute la couleur visible du site.

## Typographie

Utiliser deux familles maximum :

1. Une serif éditoriale pour les grands titres et certains éléments de marque.
2. Une sans-serif très lisible pour les textes, navigation et informations pratiques.

L’ensemble doit évoquer un magazine imprimé contemporain.

Éviter :

* les typographies manuscrites ;
* les polices wedding clichés ;
* les typographies décoratives difficiles à lire.

## Mise en page

Utiliser beaucoup d’espace blanc.

Les photos doivent être grandes.

Préférer une seule grande image à une mosaïque de nombreuses petites images.

La homepage doit contenir environ 8 à 12 photographies fortes.

Les compositions asymétriques sont autorisées si elles restent élégantes et lisibles.

Les éléments peuvent volontairement respirer sur de grands espaces verticaux.

## Interface

Éviter autant que possible :

* cartes ;
* ombres ;
* dégradés ;
* coins arrondis ;
* badges ;
* blocs colorés ;
* gros boutons remplis ;
* effets 3D ;
* animations décoratives.

Les CTA doivent principalement apparaître sous forme de liens typographiques élégants.

Exemple :

`DÉCOUVRIR LE MARIAGE →`

## Animations

Animations très légères uniquement :

* apparition douce ;
* léger mouvement vertical ;
* transitions d’image discrètes.

Aucun élément ne doit bouger uniquement pour attirer l’attention.

La performance reste prioritaire.

## Photographie

Le site doit valoriser :

* reportage ;
* émotions ;
* moments spontanés ;
* relations humaines ;
* portraits naturels ;
* lumière naturelle ;
* détails contextuels.

Les photos doivent être suffisamment grandes pour avoir un impact émotionnel.

## Ton éditorial

Les textes doivent être :

* simples ;
* humains ;
* directs ;
* élégants ;
* peu commerciaux.

Éviter les clichés tels que :

* « capturer votre amour » ;
* « immortaliser votre plus beau jour » ;
* « une expérience unique » ;
* « des souvenirs magiques ».

## Maintenance

Le site doit pouvoir rester visuellement pertinent plusieurs années sans publication régulière.

Alexis doit pouvoir renouveler facilement quelques photographies sans modifier le code complexe.

Les galeries doivent pouvoir être mises à jour simplement en ajoutant ou remplaçant des fichiers image.

## Règle générale

Lorsqu’une décision graphique est incertaine :

préférer la solution la plus simple, éditoriale et photographique.

Les photographies doivent toujours être plus importantes que l’interface.
