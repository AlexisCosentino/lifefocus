# LIFE FOCUS — SEO

## Objectif principal

Construire un site extrêmement performant techniquement et fortement optimisé pour les recherches locales liées à la photographie en Drôme et autour de Valence / Romans-sur-Isère.

Le SEO ne doit jamais dégrader l’esthétique ou rendre les textes artificiels.

## Architecture principale

Pages permanentes prévues :

* `/`
* `/mariage/`
* `/grossesse/`
* `/naissance/`
* `/famille/`
* `/a-propos/`
* `/contact/`

Une section éditoriale SEO pourra être ajoutée plus tard.

## SEO local

Les zones principales sont notamment :

* Drôme ;
* Valence ;
* Romans-sur-Isère ;
* Provence ;
* éventuellement Ardèche et Drôme provençale lorsque pertinent.

Ne jamais répéter artificiellement les villes dans tous les paragraphes.

Créer du contenu réellement utile autour des recherches locales.

## Pages SEO

Des pages dédiées pourront exister pour des intentions fortes telles que :

* photographe mariage Drôme ;
* photographe mariage Valence ;
* photographe mariage Romans-sur-Isère ;
* séance grossesse Drôme ;
* photographe naissance Valence.

Ces pages doivent apporter du contenu distinct et utile.

Ne jamais générer automatiquement des dizaines de pages identiques en changeant uniquement le nom d’une ville.

## Exigences techniques

Chaque page publique doit avoir :

* un `<title>` unique ;
* une meta description pertinente ;
* une URL canonique ;
* un seul H1 logique ;
* une hiérarchie H2/H3 propre ;
* des images avec dimensions explicites ;
* des textes alternatifs pertinents ;
* Open Graph ;
* métadonnées sociales pertinentes.

Le site doit également posséder :

* `sitemap.xml` ;
* `robots.txt` ;
* données structurées JSON-LD pertinentes ;
* page 404 ;
* URLs propres ;
* liens internes cohérents.

## Performance

Le site doit être conçu pour obtenir d’excellents Core Web Vitals.

Limiter drastiquement :

* JavaScript client ;
* polices lourdes ;
* scripts tiers ;
* images trop grandes.

Utiliser les fonctions d’optimisation d’images d’Astro.

Préférer AVIF/WebP lorsque pertinent.

Lazy loading sous la ligne de flottaison.

L’image principale LCP doit être chargée en priorité.

## Migration

Le domaine `lifefocus.fr` existe déjà.

Avant la mise en production du nouveau site :

1. inventorier les anciennes URLs ;
2. conserver les URLs pertinentes lorsque possible ;
3. créer des redirections 301 lorsque leur structure change ;
4. éviter toute suppression massive de pages indexées ;
5. vérifier les changements dans Google Search Console.

Ne jamais modifier arbitrairement une URL existante sans vérifier son rôle SEO.

## Contenu

Le contenu doit être conçu pour des humains avant les moteurs de recherche.

Pas de keyword stuffing.

Pas de paragraphes ajoutés uniquement pour augmenter artificiellement la longueur des pages.

Privilégier :

* expertise réelle ;
* expérience personnelle ;
* informations locales ;
* conseils pratiques ;
* contenu original.

## Images

Les photographies sont essentielles au site.

Chaque image importante doit avoir :

* un nom de fichier compréhensible lorsque possible ;
* des dimensions adaptées ;
* un alt pertinent lorsque l’image apporte une information ;
* aucun alt artificiellement bourré de mots-clés.

## Principe absolu

Toute décision SEO doit préserver trois priorités :

1. pertinence pour le visiteur ;
2. vitesse ;
3. compréhension claire de la page par Google.
